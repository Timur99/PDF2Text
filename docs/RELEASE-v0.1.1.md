PDF2Text 0.1.1 исправляет упаковку приложения для macOS: подпись теперь покрывает
всё приложение, встроенный Python и библиотеки. Сборка проверяет подписи перед
созданием DMG и останавливается при ошибке.

## Требования

- Mac на Apple Silicon (M1 и новее).
- macOS 13 Ventura или новее.

## Установка и первый запуск

Эта тестовая сборка использует ad-hoc подпись. Сертификата Developer ID и
нотаризации Apple у неё нет, поэтому macOS всё ещё может блокировать запуск.
Исправление подписи не заменяет разрешение Gatekeeper.

1. Скачайте `PDF2Text-0.1.1.dmg`, откройте его и перетащите **PDF2Text** в
   «Программы», заменив предыдущую версию.
2. Попробуйте открыть приложение. Если в **Системные настройки → Конфиденциальность
   и безопасность** появилась кнопка **«Всё равно открыть»**, используйте её.
3. Если кнопки нет и запуск заблокирован, проверьте установленную копию в Терминале:

   ```bash
   codesign --verify --deep --strict --verbose=2 /Applications/PDF2Text.app
   ```

   При ошибке проверки скачайте образ заново. Если проверка успешна и вы доверяете
   источнику сборки, снимите карантин только с этого приложения и запустите его:

   ```bash
   xattr -dr com.apple.quarantine /Applications/PDF2Text.app
   open /Applications/PDF2Text.app
   ```

Команда снимает ограничение карантина; она не подтверждает безопасность или
происхождение приложения и не исправляет повреждённые файлы.

## Контрольная сумма

Рядом с образом находится файл `PDF2Text-0.1.1.dmg.sha256`. Сравните его значение
с выводом команды:

```bash
shasum -a 256 PDF2Text-0.1.1.dmg
```

Распознавание и обработка документов не изменены в этой версии.
