# Подключение PDF2Text MCP

Задача агента — подключить сервер к текущему MCP-клиенту. Используй контекст
текущей сессии; выполняй обычные действия установки самостоятельно.

1. Используй существующую установку PDF2Text. Если её нет, клонируй
   https://github.com/Timur99/PDF2Text в постоянный пользовательский каталог,
   создай venv на Python 3.11+ и установи пакет из него:
   `python -m pip install ".[mcp,vision]"` на macOS,
   `python -m pip install ".[mcp,ocr]"` на Windows/Linux.
   Команды выполняй интерпретатором созданного venv. Рабочую установку
   переустанавливать или обновлять ради подключения не нужно.
2. Добавь или обнови только запись `pdf2text` в настройках текущего клиента,
   сохранив остальные подключения. Параметры:
   - транспорт: **stdio**;
   - команда: абсолютный путь к `.venv/bin/pdf2text-mcp`
     (Windows: `.venv/Scripts/pdf2text-mcp.exe`);
   - аргументы: `["--allow-dir", "/абсолютный/путь/к/рабочей/папке"]`.
   Сохрани уже настроенные каталоги доступа. Для нового подключения используй
   папку документов из запроса или текущий проект. Если подходящей рабочей
   папки нет, создай `PDF2Text` в пользовательской папке Documents и используй её.
   Домашний каталог целиком и корень диска не выбирай по умолчанию.
3. Перечитай подключения средствами клиента, если это доступно. Достаточно увидеть
   `extract_text` и `list_engines` в списке инструментов. Если клиент требует
   перезапуска, сообщи об этом: не заменяй его отдельным тестовым стендом.

Не запускай тесты проекта, бенчмарки, обработку PDF или изображений для установки.
Не создавай тестовые документы. Дополнительную диагностику выполняй только при
ошибке подключения. Сам сервер запускается клиентом; вручную держать процесс не нужно.

В конце — короткий результат: «PDF2Text подключён» или «Настройка добавлена,
нужен перезапуск клиента». Если подключение не удалось, укажи конкретную причину.
Не сообщай об успешном подключении, пока клиент его не подтвердил.

Технические подробности при необходимости: [MCP.md](MCP.md).
